# 👨‍🏫 Deep-Learner: 启发式 Agentic RAG 导师

欢迎使用 **Deep-Learner**！这是一个基于 **LangGraph** 驱动的高级教学助手。

### 🚀 技术亮点
- **Agentic Workflow**: 采用 Planner -> Retriever -> Tutor -> Critic 闭环架构。
- **Hybrid Retrieval**: 集成 Milvus 向量库与 Elasticsearch 关键词检索。
- **逻辑审计 (Self-Correction)**: 内置 Critic 节点，严格检测幻觉与逻辑矛盾。
